## Brand & Style

This design system targets high-performance athletes, quantified-self enthusiasts, and tech-forward fitness consumers. The visual identity merges the surgical clarity of premium telemetry instrumentation with the kinetic drive of competitive athletics.

The aesthetic follows an **engineered technical precision** style—a synthesis of high-contrast minimalism, dark telemetry glass, and vivid bio-luminescent accents. Visuals avoid generic gym tropes (heavy grit, distressed textures) in favor of refined laboratory analytics, pure contrast, and sharp micro-details inspired by avionics displays and luxury biometric wearables. 

The interface should evoke three core physical sensations:
1. **Clinical Accuracy:** Uncompromising data fidelity, crisp structural lines, and instantaneous legibility under intense motion or direct sunlight.
2. **Kinetic Drive:** High-converting, reactive accents that telegraph energy states, vital surges, and direct paths to conversion.
3. **Engineered Luxury:** Deep, light-absorbing midnight surfaces contrasted with ultra-fine, glass-like boundaries.

## Colors

The color architecture is built around a dark telemetry foundation designed for maximum data contrast and prolonged visual focus. 

- **Primary (`#05DF72` - Kinetic Lime):** Reserved for singular primary conversion actions, positive biometric feedback loops, real-time performance thresholds, and critical conversion triggers. Never dilute its impact by using it as a large background wash.
- **Secondary (`#00F0FF` - Aero Cyan):** Represents rapid data telemetry, connectivity indicators, target metrics, pacing guidelines, and interactive secondary highlights.
- **Tertiary (`#10B981` - Deep Mint):** Bridges data states, recovery metrics, confirmed baselines, and secondary metric progression rings.
- **Surface Foundations:**
  - Base Obsidian: `#0B0F17` (Deepest canvas backing)
  - Card & Container Fill: `#111827` (Layer 1 elevations)
  - Interactive Elevated Surface: `#1F2937` (Layer 2 sheets, active controls)
- **Text & Light Tiers:**
  - High-Emphasis Data / Headers: `#FFFFFF`
  - Body & Contextual Typography: `#F9FAFB`
  - Dimmed / Secondary Units: `#9CA3AF`
- **Boundaries & Stroke Geometry:**
  - Structural Division: `#1F2937`
  - Highlighting / Keyline: `#374151`
  - High-contrast interactive border hover: `#4B5563`

## Typography

The type system balances technical athleticism with high-speed readability. 

- **Space Grotesk** is deployed across headlines, high-impact conversion copy, numeric metrics, and telemetry readouts. Its subtle geometric quirks and mechanical ink traps evoke digital timers, GPS computers, and aerospace heads-up displays.
- **Inter** provides high legibility for dense UI labels, technical documentation, feature lists, and analytical paragraphs. 

All numbers within dashboards and tables must use tabular figures (`font-variant-numeric: tabular-nums`) to prevent jumping numbers during real-time streaming updates. Micro-labels that indicate sensor status, zones, or units should use `label-caps` in uppercase tracking.

## Layout & Spacing

The layout is built upon an 8-point structural baseline using a fluid grid architecture that adjusts strictly across three key viewport conditions:

- **Desktop (1200px+):** 12-column grid, max-width 1360px centered canvas, 24px (`gutter`) column separation, 32px (`margin`) outer border pad. Allows complex multi-metric arrays, side-by-side data dashboards, and conversion split-screens.
- **Tablet (768px – 1199px):** 8-column grid with 20px gutters and 24px margins. Biometric dashboards collapse secondary charts into horizontally scrollable carousels.
- **Mobile (Below 768px):** 4-column layout with 16px (`gutter-mobile`) and 16px (`margin-mobile`). All primary CTA elements pin to the viewport bottom with integrated safe-area padding.

Spacing rhythm follows an uncompromising logic: layout groupings use `space-xl` for sectional clearance, `space-lg` for card internal separation, and `space-sm` for inline metric/icon pairings.

## Elevation & Depth

Depth is defined through stacked luminescence rather than skeuomorphic drop-shadows. Because the canvas is pitch black, elevation must be felt via surface tinting and ultra-fine, razor-sharp edge illumination.

- **Level 0 (Canvas Base):** Pure `#0B0F17`. Non-interactive baseline viewport background.
- **Level 1 (Structural Cards & Panels):** Solid `#111827` fill bordered by a 1px solid stroke in `#1F2937`. Casts no drop shadow.
- **Level 2 (Modals, Overlays, Floating Controls):** `#1A2234` fill paired with a top-weighted highlight stroke (`rgba(255, 255, 255, 0.08)` along the top edge, `#1F2937` along sides and bottom). Elevated with a deep ambient shadow: `0 20px 40px -15px rgba(0, 0, 0, 0.7)`.
- **Level 3 (Bio-Telemetry Glow & Conversion Focus):** Reserved exclusively for primary conversion items and active tracking elements. Uses a zero-spread radial neon diffusion: `0 0 24px 0 rgba(5, 223, 114, 0.22)`. On hover, this expands to `0 0 32px 4px rgba(5, 223, 114, 0.35)`.
- **Glassmorphic Hud Elements:** Used sparingly for sticky overlays and metric headers. Background is `rgba(17, 24, 39, 0.8)` with `backdrop-filter: blur(16px)` and a 1px border of `rgba(255, 255, 255, 0.06)`.

## Shapes

The design system implements a refined curvature scale (`roundedness: 2` — base radius of 8px). 

- **Containers & Metric Panels:** Use `rounded-lg` (16px) to emulate the refined screen curvature of modern flagship smartwatches.
- **Buttons, Inputs, & Action Chips:** Use `rounded` (8px) for crisp, tactile target interaction.
- **Status Pills & Micro Badges:** Strictly fully pill-shaped (`rounded-full` / 9999px) to contrast against structural card geometry.
- **Charts & Bar Trackers:** Progress tracks utilize full radial caps on interior fills while maintaining crisp alignment with data grids.

## Components

### Buttons
- **Primary Action (Conversion / "Buy Now" / "Start Workout"):** Solid `#05DF72` background with `#0B0F17` ultra-bold text (`Space Grotesk`, 600 weight). Edge radius of 8px. Hover triggers a subtle scale expansion (1.015x) alongside the Level 3 green telemetry bloom (`0 0 24px rgba(5, 223, 114, 0.28)`).
- **Secondary (Telemetry / Alternate Action):** `#111827` surface with a 1px `#374151` boundary and `#F9FAFB` text. Hover shifts border color to `#00F0FF` with text illuminating to `#00F0FF`.
- **Ghost Action:** Pure transparent background, 1px transparent border, high-contrast text `#9CA3AF`. Hover brightens text to `#FFFFFF` with an underlying surface transition to `#1F2937`.

### Metric & Telemetry Cards
- Encased in `#111827` with a 1px `#1F2937` perimeter stroke.
- Header contains an uppercase category label (`label-caps`) in `#9CA3AF`, flanked by an optional live-status indicator (e.g., pulsing `#05DF72` micro-dot).
- Numeric readouts use `metric-xl` or `metric-md` in high-contrast `#FFFFFF`. Units (`BPM`, `KCAL`, `WATT`, `VO2`) sit immediately adjacent in muted `#9CA3AF` using `Space Grotesk`.

### Chips & Filter Pills
- Pill-rounded (9999px). Inactive state: `#111827` background, 1px `#1F2937` border, `#9CA3AF` text. 
- Active state: `#1F2937` surface with an accent border in `#00F0FF` or `#05DF72`, accompanied by matching text color and an inset 6px indicator pip.

### Input Fields
- Form inputs feature a solid `#0B0F17` recessed well, surrounded by a 1px `#1F2937` stroke with an 8px radius. Text is entered in `#F9FAFB` with `#6B7280` placeholder states.
- Focus state activates an instantaneous high-tension border in `#00F0FF` and a microscopic outer bloom (`0 0 0 2px rgba(0, 240, 255, 0.15)`).

### Toggles, Checkboxes & Radio Controls
- **Toggle Switches:** Recessed track in `#1F2937` (44px wide by 24px high). Activated state snaps track fill to `#05DF72` with an inner 20px sliding handle in `#0B0F17`.
- **Checkboxes:** 20px square, 4px corner radius. `#0B0F17` base with 1.5px `#374151` border. Checked state transitions background to `#05DF72` with a high-contrast `#0B0F17` checkmark icon.

### Heart-Rate / Strain Progress Gauges
- Integrated radial and horizontal gauge meters constructed with a `#1F2937` track background.
- Dynamic fills execute smooth CSS linear gradients transitioning from `#10B981` (optimal baseline) to `#05DF72` (peak performance) and capped with `#00F0FF` (overdrive threshold).
